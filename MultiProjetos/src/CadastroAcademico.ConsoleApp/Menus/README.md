# Menus

Contem os menus textuais e o dispatcher principal da interface console.

| Arquivo | Responsabilidade |
|---|---|
| `MenuPrincipal.cs` | Dispatcher raiz — instancia submenus e roteia para cada contexto. |
| `MenuCursos.cs` | CRUD completo de cursos. |
| `MenuAlunos.cs` | CRUD completo de alunos. |
| `MenuMatriculas.cs` | Gerenciamento de matriculas (realizar, cancelar, concluir, excluir). |
| `MenuRelatorios.cs` | Relatorios e consultas derivados das matriculas. |
