# Como Usar Esta Fundamentacao

## Objetivo

Esta trilha explica nao apenas o que foi criado, mas por que as escolhas arquiteturais foram adotadas.

## Ordem sugerida de estudo

1. Leia os principios arquiteturais.
2. Veja as decisoes aplicadas no projeto.
3. Compare a estrutura antes e depois.
4. Estude a diferenca entre entities, value objects e enums na pratica.
5. Use o guia para criar novas classes no local correto.
6. Revise os erros comuns.
7. Resolva o exercicio guiado e compare com o gabarito comentado.

## Resultado esperado para o aluno

Ao final, o aluno deve conseguir:

1. Explicar a diferenca entre organizar por tecnologia e por responsabilidade.
2. Criar novos arquivos sem gerar desorganizacao.
3. Entender como a estrutura facilita manutencao e evolucao do sistema.
