# Glossario Rapido

## Entidade

Objeto com identidade propria no dominio (exemplo: Aluno).

## Value Object

Objeto definido pelos valores, sem identidade propria (exemplo: PerfilAcademico no contexto atual).

## Caso de uso

Acao da aplicacao que coordena o dominio para entregar uma funcionalidade.

## DTO

Objeto de transporte de dados entre camadas.

## Encapsulamento

Tecnica de proteger estado interno e expor apenas o necessario.

## Coesao

Grau em que elementos relacionados ficam juntos.

## Acoplamento

Grau de dependencia entre partes do sistema.
