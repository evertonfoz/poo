# Principios Arquiteturais da Organizacao

## 1. Responsabilidade unica por pasta

Cada pasta deve ter um papel claro. Isso reduz ambiguidades e acelera manutencao.

## 2. Coesao alta, acoplamento baixo

Classes com objetivo parecido devem ficar proximas. Camadas diferentes devem depender o minimo possivel umas das outras.

## 3. Crescimento previsivel

Uma boa estrutura antecipa o crescimento. Novas features entram em locais ja esperados, sem precisar refatorar toda a arvore de pastas.

## 4. Leitura orientada por intencao

Quem abre o projeto precisa entender o sistema pelo nome das pastas, antes mesmo de ler o codigo.

## 5. Ensino por arquitetura explicita

Como o projeto tem objetivo didatico, a estrutura deve ensinar. A pasta tambem e parte da documentacao.
