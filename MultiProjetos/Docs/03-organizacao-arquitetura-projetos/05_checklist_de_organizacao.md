# Checklist de Organizacao

## Checklist rapido

1. Nenhuma entidade de dominio no root do projeto.
2. Classes de aplicacao separadas por responsabilidade (`Services`, `DTOs`, `Results`).
3. Console e Blazor organizados por pasta de interface.
4. Build da solution continua verde apos reorganizacao.
5. Estrutura preparada para crescimento sem refactor estrutural imediato.

## Indicador de qualidade

Se um novo membro do time identifica onde criar cada arquivo em menos de 1 minuto, a organizacao esta boa.
