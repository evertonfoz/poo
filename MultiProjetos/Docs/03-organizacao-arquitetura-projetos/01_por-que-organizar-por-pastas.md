# Por Que Organizar Por Pastas

## Objetivo

Padronizar a estrutura dos projetos para facilitar manutencao, leitura e evolucao do sistema.

## Beneficios

1. Facilita localizacao de arquivos por responsabilidade.
2. Reduz acoplamento entre camadas.
3. Torna onboarding mais rapido.
4. Evita crescimento desordenado no root dos projetos.

## Regra pratica

Cada pasta deve representar uma responsabilidade clara. Se uma classe nao tem "casa", a arquitetura ainda nao esta explicita.
